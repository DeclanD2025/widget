# 11 — Patterns of Play (Automatisms)

Earlier chapters explained *principles*. This chapter shows the **concrete, repeatable
patterns** ("automatisms") teams rehearse to apply those principles. When you see the same
pattern twice in a match, you have found a team's plan.

### Diagram key

```
↑ = attacking direction         ○ = attacker (in possession)
●  = defender                    ⌀ = ball / ball-carrier
- -> = pass                      ==> = dribble / carry
 ~~> = run without the ball      [GK] = goalkeeper
```
Diagrams are schematic, viewed with the attack moving **up** the page.

---

## A. Build-Up Patterns

### 1. The split + drop (beating a two-man press)
The centre-backs split wide, the pivot drops between them to make a 3v2, the full-backs
push high.

```
            ●        ●            <- two pressing forwards
        ⌀
   ○CB - - - - ○DM - - - - ○CB    <- 3 vs 2: a free man always exists
              [GK]
```
*Principle:* numerical superiority in the first line (Ch. 00, 03). The free man advances
the ball.

### 2. Third-man through the pivot
The opponent blocks the direct pass to the striker, so the ball goes via a third player.

```
        ○ striker (marked)  ●
         ^
         ~~ checks short
   ○CB --⌀--> ○DM --------> ○striker (now free, defender stepped wrong)
```
*Principle:* the third-man combination (Ch. 03). A→B drags a marker; B→C exploits the
vacated space.

### 3. Goalkeeper as the bait-and-switch
Invite the press to one side, then use the keeper to switch to the free far side.

```
   ●●● press the left
   ○CB(L) -⌀                 ○CB(R) free
        \                    /
         [GK] - - - - - - - >        <- keeper switches play
```

## B. Progression Patterns

### 4. The "up-back-through" (the layoff)
Play forward into a striker, who lays it back to a runner, who plays the killer through-ball.

```
              ○ striker
              |  (lays back)
   1. up ⌀    v   2. back
   ○8 ------> ○ -------> ○8/10
                          |  3. through
                          v
                      ~~> ○ runner in behind
```
*Why it works:* it turns the defence around — the first pass goes in, the third pass goes
through, while defenders are still reacting to the first.

### 5. Overload to isolate (the full switch)
Crowd one flank to drag the defence across, then switch to the isolated winger.

```
  LEFT (overload)                         RIGHT (isolated)
  ○ ○ ○ ●●●  draw defenders   - - - - - >  ○ winger 1v1 ●
        ⌀ ----------- long switch ---------^
```
*Principle:* combine positional + qualitative superiority (Ch. 00, 03).

### 6. Third-man wide rotation (winger–full-back–8)
A rotation that unbalances a flank: winger comes inside, full-back overlaps, the 8 fills.

```
   ○W ~~> inside            ○8 ~~> fills wide-mid space
        \
   ○FB ~~> overlaps outside ⌀ ==> crosses
```

## C. Final-Third / Chance-Creation Patterns

### 7. The cut-back
Reach the byline, pull it back to the penalty spot for an arriving runner.

```
                 GOAL
        ●  [GK]  ●
     ○ near   ○ spot   ○ pull-back (top of box)
                 ^   ^
                 |   pulled back ⌀
   ○ winger ==> byline
```
*Why it's elite:* defenders face their own goal; the runner faces the ball with the whole
goal in view (Ch. 03).

### 8. The third-man run into the box
A decoy occupies the centre-back; a midfielder arrives late, unmarked.

```
        ○ striker (pins CB ●)
                              ~~> ○8 arrives late
   ○ winger -⌀- - - - - - - - - ->  (cut-back to the 8)
```

### 9. Near-post flick / far-post arrival (open play)
Cross to the near post for a flick-on; a far-post runner attacks the second ball.

```
                GOAL
   ○ near (flick) >>  ○ far (arrives)
        ^
   ⌀ cross from wide
```

## D. Defending Patterns

### 10. The pressing trap (show them the line)
Angle the press so the only pass is wide, then trap against the touchline.

```
   ●FW shows inside-passing-lane shut
        \  (ball forced wide)
   ○FB receives ⌀  ->  ●W + ●FB + ●8 collapse: trap
   touchline ============================== (acts as extra defender)
```
*Principle:* the touchline as a defender; cover shadow (Ch. 04).

### 11. Pass-on / hand-off in a zonal block
A runner moving between zones is handed from one marker to the next, nobody chasing out of
shape.

```
   ●8a "I have him" ~~runner~~> ●8b "I've got him now"
   (●8a stays in zone)          (●8b picks up)
```

### 12. Rest-defence on the counter
On a turnover, the deepest two-three players delay and funnel the break inside to cover.

```
   ⌀ lost here
   ○->●  counter
   ●CB jockeys (delays) <-- ●DM recovers
   ●CB covers central         ~~> teammates sprint back
```

---

## How to use this chapter when watching

1. Identify **which pattern** a team keeps returning to — that is its primary plan.
2. Note **which pattern the opponent has no answer for** — that is where the goals will come.
3. When a goal is scored, **rewind to the pattern** that created it; the visible finish is
   the end of a rehearsed sequence.

> The same pattern executed twice is a **plan**; executed once is a coincidence; defended
> twice is a **counter-plan**. Reading a match is largely pattern-spotting.
