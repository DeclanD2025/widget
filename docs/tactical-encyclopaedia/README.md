# ⚽ Football Tactical Encyclopaedia

A complete, structured reference for understanding football tactics — and a practical
framework for **reading and predicting matches** from a tactical point of view.

It is written to be read in order as a course, or dipped into as a reference. Parts I–III
build the vocabulary; Parts IV–VII cover the live phases of play; Parts VIII–X add depth,
people and history; the **Companion Volume** turns all of it into a repeatable match-day
method.

## How to use this

- **New to tactics?** Read `00` → `01` → `08` (glossary) first. They are the shared language
  everything else depends on.
- **Want the analytical heart?** Go straight to `03`, `04`, `05` — the four phases of play.
- **Just want to read/predict games?** Jump to `10` and keep the glossary open beside it.

Every chapter uses the same lens: **space, time, numbers, position, individual quality.**

## The five reference points (read everything through these)

1. **Space** — where it is, who controls it, how it is created or denied.
2. **Time** — tempo, when actions happen, speed of decision.
3. **Numbers** — overloads, equalities, underloads (2v1, 3v2…).
4. **Position** — body shape, orientation, available lines of pass.
5. **Individual quality** — the variable that breaks any structure.
