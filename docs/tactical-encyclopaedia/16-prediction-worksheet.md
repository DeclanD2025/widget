# 16 — Match Prediction Worksheet

A fillable, repeatable template that turns the whole encyclopaedia into a single match
prediction. Copy the blank version for any fixture; a worked example follows.

> This is a **structured opinion engine**, not a betting formula. Its output is a confidence
> *tier* and the most likely *upset route* — because football is low-scoring and high-variance.

---

## The blank worksheet

```
FIXTURE: ________________  vs  ________________     DATE: __________
COMPETITION: __________________   VENUE (home team): __________________

1) IDENTITY BY PHASE                         TEAM A            TEAM B
   In-possession shape & style:           __________        __________
   Defensive block & press:               __________        __________
   Transition behaviour:                  __________        __________
   Intended game state (ball/counter):    __________        __________

2) BATTLE MAP (tick the edge)                                  EDGE (A/B/=)
   Build-up shape vs press (who gets +1?)                      ______
   Attacking width vs defensive width                          ______
   Transition speed vs rest defence                            ______
   Midfield numbers (per phase)                                ______
   Half-space / between-the-lines access                       ______
   Set-piece quality (deliver + target vs defend)              ______
   Key individual mismatches                                   ______

3) STYLE CLASH (one line):
   Does A's strength attack B's weakness? ______________________________
   Does B's strength attack A's weakness? ______________________________

4) CONTEXT MULTIPLIERS                        TEAM A            TEAM B
   Motivation / league stakes:            __________        __________
   Fatigue / congestion / rotation:       __________        __________
   Home advantage:                        __________        __________
   Form (last ~6):                        __________        __________
   Injuries / suspensions (key):          __________        __________

5) SCORING  (rate each team 1–5; weight in brackets)
   Phase dominance        (x3): A __  B __
   Match-up edges         (x3): A __  B __
   Style-clash outcome    (x2): A __  B __
   Set-piece edge         (x1): A __  B __
   Context multipliers    (x2): A __  B __
   Variance / X-factor    (x1): A __  B __
   -------------------------------------------
   WEIGHTED TOTAL:              A ___  B ___

6) OUTPUT
   Favoured side: __________     Tier: Lean / Likely / Lock
   Main upset route: ________________________________________________
   What I'll watch first (the deciding battleground): ________________
   One-line thesis: _________________________________________________
```

### Scoring guide
- Rate each factor **1–5** for each team (5 = clear strength in this match-up).
- Multiply by the weight, sum per team.
- **Gap → tier:** small gap = **Lean**; clear gap across several rows = **Likely**; large gap
  *and* favourable context = **Lock** (which still loses sometimes — size confidence to
  variance).
- Always write the **upset route**: the single most likely way the underdog wins. If you
  can't name it, you haven't understood the game yet.

## Worked example (archetypes)

```
FIXTURE: City-type (A)  vs  Counter-type (B)     VENUE: A (home)

1) IDENTITY
   In-possession:   A: positional, 3-2-5     B: low block, direct counter
   Defensive:       A: high press            B: 5-4-1 deep block
   Transition:      A: counterpress          B: fast counter, lone pacey 9
   Game state:      A: wants the ball         B: wants to counter

2) BATTLE MAP                                          EDGE
   Build-up vs press (+1?)        A builds 3-2 vs 1     A
   Width vs width                 A's width vs 5-back    =
   Transition speed vs rest def   B fast vs A's 2-3      B
   Midfield numbers               A overloads centre     A
   Half-space access              A's mezzalas           A
   Set-piece quality              even deliverers        =
   Key mismatches                 A's winger vs B's WB   A

3) STYLE CLASH
   A's possession attacks B's compact block — slow, needs patience/quality.
   B's pace attacks the space behind A's high line on the counter.

4) CONTEXT
   A: home, strong form, slight fixture fatigue.
   B: nothing-to-lose underdog, fresh, dangerous on the break.

5) SCORING (weighted)
   Phase dominance   x3:  A5=15  B2=6
   Match-up edges    x3:  A4=12  B2=6
   Style outcome     x2:  A3=6   B3=6
   Set-piece edge    x1:  A3=3   B3=3
   Context           x2:  A4=8   B3=6
   Variance/X-factor x1:  A3=3   B4=4
   TOTAL:                 A=47   B=31

6) OUTPUT
   Favoured: A   Tier: Likely (not Lock — B's counter keeps it live)
   Upset route: A over-commits, loses the ball high, B's 9 punishes the
                high line on the break; or a B set piece in a low-event game.
   Watch first: A's rest defence on turnovers + how B's 9 attacks the line.
   Thesis: "A controls the ball and territory and should win, but its
            high line vs B's pace on the counter is the live danger; if A's
            rest defence holds, A wins comfortably."
```

---

## Using the worksheet over a season (this is how you improve)

1. **Fill it before** each match you watch closely.
2. **Grade it after** (Ch. 10, post-match loop): which edges showed up? what surprised you?
3. **Track your tiers**: are your "Likely" calls landing ~70%? your "Leans" ~55%? Calibration
   — knowing how confident to *be* — is the real skill, more than any single prediction.
